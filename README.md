# Hajer Hamza — Interactive Portfolio

A responsive, customizable portfolio website built with plain HTML, CSS and JavaScript.

## Features
- Responsive design for desktop and mobile
- Dark/light mode with saved preference
- Scroll reveal animations
- Interactive cursor glow
- Animated skills/experience sections
- No framework or build step required
- Ready for GitHub Pages

## Run locally

Open `index.html` in a browser.

For a local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish on GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js` and `README.md`.
3. Go to **Settings → Pages**.
4. Select the repository branch and `/ (root)`.
5. Save. GitHub will provide the live portfolio URL.

## Customize

Most content is in `index.html`.

Colors, typography and layout are in `style.css`.

The theme toggle, animations and interactive cursor are in `script.js`.

### Easy things to change
- Name and title
- Contact details
- Experience
- Skills
- Education
- Accent colors (`--accent` and `--accent2`)
- Fonts
- Section order
- GitHub/social links

## Source basis

The professional content in this portfolio is based on the supplied CV for Hajer Hamza, including the professional profile, experience, skills, education, certifications and languages.
